# 🍽️ Platterly

### A Full-Stack Food Ordering Web Application
**Platterly** is a food ordering web app built with **Java Servlets and JSP**. It covers the complete customer journey, from discovering restaurants to placing an order and viewing order history.

Built as part of my learning journey at **TAP Academy**.

🎥 **Demo video:** [Watch on LinkedIn](https://www.linkedin.com/in/laxmi-sannagoudra-86275a300/?isSelfProfile=true) 

---

## ✨ Features

| | Feature |
|---|---|
| 🔍 | Search for restaurants, cuisines or dishes |
| 🍴 | Browse restaurants and filter by cuisine |
| 📋 | Detailed restaurant menus with prices and descriptions |
| 🔐 | User registration and login (login required before ordering) |
| 🛒 | One-click add to cart with live floating cart bar |
| ➕ | Multi-restaurant cart, with dishes from different restaurants in one order |
| 🔢 | Quantity adjustment and order summary with grand total |
| 📍 | Checkout with delivery address |
| 💳 | Cash on Delivery and Online Payment (UPI QR) |
| ✅ | Instant order confirmation with Order ID |
| 📦 | My Orders page for current and past orders |
